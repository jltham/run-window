Each condition is checked across your whole run, using its worst value. The verdict is the worst condition. When sources disagree, the worse one wins. If it's raining at your nearest NEA rain station, "Start now" is a No-go.

Any start time counts, day or night. The best window is the earliest Go start in the next 24 hours, and "Leave" shows how late you can still start and stay in the Go.

Confidence is high when the run falls inside NEA's 2-hour nowcast, medium 2–6 hours ahead, low further out. If thunderstorm or PM2.5 data is missing, you'll see "Can't confirm" instead of a guess.
