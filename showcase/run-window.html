The worse source wins

If NEA's nowcast says "Thundery Showers" and the model says 10% rain, it's a No-go.

Why it exists

Singapore showers form fast and very locally. Weather apps show a moment or a whole region, so committing to a 2–3 hour run means checking several apps and still guessing.

Build plan

Each stage is usable on its own. The biggest risk, forecast accuracy, is tested first and cheaply.

Back-test the forecast

Compare 60 days of past Open-Meteo forecasts with real NEA rain-station readings. Under ~70% right, the outlook gets shortened or marked uncertain.

Start-now verdict

NEA nowcast, live rainfall and PM2.5 give Go / Caution / No-go for a run starting now.

12-hour outlook

Hourly forecasts, run length, confidence labels and "Leave by".

Ready to share

Saved settings, clear errors, home-screen install, deployment.
