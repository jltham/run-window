Each condition is checked across your whole run, using its worst value. The verdict is the worst condition. When sources disagree, the worse one wins. If it's raining at your nearest NEA rain station, "Start now" is a No-go.

Run hours avoid office and meal times: weekdays 5:30–8:30am and 6–7:30pm, weekends 6–11:30am and 3–7:30pm. The whole run has to fit inside one of them.

Confidence is high when the run falls inside NEA's 2-hour nowcast, medium 2–6 hours ahead, low 6–12 hours ahead. If thunderstorm or PM2.5 data is missing, you'll see "Can't confirm" instead of a guess.
